# JATS Journal Publishing 1.3

RELAX NG schema modules downloaded from the NLM release directory:
https://jats.nlm.nih.gov/publishing/1.3/rng/

Entry point: `JATS-journalpublishing1-3.rng`. The modules are unmodified and
retain their original public-domain notices. The tag-set documentation is
at https://jats.nlm.nih.gov/publishing/tag-library/1.3/ . Validation runs
offline with lxml; external DTD loading and network resolution are disabled.
